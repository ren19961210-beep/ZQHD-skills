# Seedance 2.0 汽车工作流

## 车辆身份卡

```text
品牌/车型/年款（只写用户确认的）：
车身类型与比例：
车漆：
灯组、轮毂、车标位置、玻璃、门把手、外观套件：
内饰颜色、座椅、方向盘、中控布局（只写看得见的）：
必须保持：
允许变化：
禁止出现：竞争车型、错误车标、额外主车、错误内饰、随机车牌文字
```

真实车型优先准备正面/前 3/4、侧面、后 3/4 三类外观视图；做内饰时再准备驾驶位、前排或中控图。参考图冲突时，减少素材比继续堆素材更稳。

## 素材所有权

```text
外观图 → 车型身份、比例、车漆、灯组和轮毂
内饰图 → 座舱布局、座椅、材质和光线
白模/三视图 → 空间、机位、阻挡和路径（若当前 2.0 平台支持）
运动视频 → 运镜、动作节奏和速度
细节图 → 车灯、轮毂、门把手等局部
```

提示词中同时写排除项：运动视频不负责车辆品牌，内饰图不负责整车外观，细节图不负责整车比例。

## 稳定镜头

- 低机位侧向跟拍：主车保持画面中部，摄像机与车速同步；不要同时环绕和升降。
- 固定三脚架中景：车辆从左进入、在右侧停下；摄像机不追车。
- 静态展示后推近灯组：推近完成后保持，不再突然切换视角。

## 复杂动作

换电或装配写成：车辆静止且四轮接地 → 设备接触并承托 → 旧部件下降/移出 → 新部件进入并对位 → 锁定 → 车辆回到可行驶状态。若关键接触看不清，拆成多个短镜头；不要把安全动作或结构变化全压在一个镜头里。

## 验收

逐段检查车型、车漆、灯组、轮毂、车标、车门/车窗数量、外景到内饰切换、行驶方向、车轮/悬架、主运镜、复杂动作顺序、对白和背景车辆。文字和车标逐字不通过时，不称为合格成片。
