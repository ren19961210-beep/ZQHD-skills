# H3 Product Ad —— MiniMax H3 产品广告提示词

## 何时使用

用户要用 MiniMax H3（开放平台 API 或海螺 WebApp）制作**产品广告**视频时使用：

- 汽车/新能源车广告、新品发布短片、产品展示、卖点演示、生活方式场景广告
- 输入可能是：产品资料、卖点清单、广告文案、参考图/参考视频/参考音频
- 需要产出：符合 H3 官方格式的完整提示词 + API 调用参数（模型/时长/比例/分辨率）

## 工作流

1. **确认模式**（看素材和用户意图）：
   - T2VA 文生视频：只有文字
   - I2VA 首帧：文字 + 1 张首帧图
   - FL2VA 首尾帧：文字 + 首尾 2 张图
   - L2VA 尾帧：文字 + 1 张尾帧图
   - Ref2VA 全参考：文字 + 任意参考图/参考视频/参考音频
2. **收集产品五要素**：品牌与型号、外观特征（配色/材质/线条）、核心卖点（按重要性排序）、屏幕文字（logo/口号原文）、目标时长与发布平台（横屏/竖屏）。
3. **读取对应参考指南**：
   - T2VA / I2VA / FL2VA / L2VA → [references/base-modes-guide.md](references/base-modes-guide.md)
   - Ref2VA → [references/ref2va-guide.md](references/ref2va-guide.md)
   - API 参数与调用 → [references/api-quickstart.md](references/api-quickstart.md)
   - 现成模板 → [references/product-ad-templates.md](references/product-ad-templates.md)
4. **按广告结构组织时间线**：开场钩子 → 产品亮相 → 卖点展示（特写）→ 场景体验 → 情感收尾 → 品牌露出（logo/口号）。
5. **写出提示词**：主体用英文（官方要求），台词/屏幕文字保留原文语言；镜头、运镜、声音按官方规格逐拍描述。
6. **给出调用参数**：模式对应的模型、duration、ratio、resolution。

## 产品广告黄金结构（6 拍，按 4–15 秒压缩）

| 拍 | 作用 | 建议占位 |
|---|------|---------|
| 1 开场钩子 | 0–1s 内抓住注意力（悬念/大景/运动） | 开头 |
| 2 产品亮相 | 产品主体登场，确立外观与身份 | 1/5 处 |
| 3 卖点展示 | 核心卖点特写，一个镜头一个动作 | 中段 |
| 4 场景体验 | 产品融入使用/生活场景 | 中后段 |
| 5 情感收尾 | 氛围、光线、情绪到达高点 | 3/4 处 |
| 6 品牌露出 | logo/口号/尾板文字完整呈现 | 最后 1–2s |

短时长（4–8s）优先拍 1、2、3、6，可跳过 4、5。

## 红线（默认内置，可覆盖）

- **新能源/汽车画面排除**：烟、蒸汽、火焰、火花、爆炸一律不出现；充电/换电用干净光影表现。
- **产品特征精准锁定**：主体颜色、材质、logo、比例不得漂移；第一拍确立后各拍保持一致。
- **屏幕文字必须给原文**：logo、口号、车名用双引号原文写出，禁止翻译或改写。
- **台词逐字保留**：口播/旁白原文保留语言，用 `<d>[语言] 原文</d>` 包裹。
- **无水印**：API 输出即为官方原片；若经其他平台（如 LibTV）中转，下载时加 `--without-ai-watermark --vip`。

## 输出格式

交付给用户时包含：

1. 模式判断与理由（一句话）
2. 完整 H3 提示词（代码块，字段名用官方原文）
3. API 调用参数表（model / duration / ratio / resolution / 素材清单）
4. 若需我执行：说明将调用的端点与轮询方式（见 api-quickstart.md）
